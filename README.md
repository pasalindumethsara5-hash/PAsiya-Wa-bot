# 👑 PASIYA-MD WHATSAPP BOT 👑

Supiri modern WhatsApp Bot ekak, **PASIYA** name eken hadapu full-featured Multi-Device Baileys Bot!

---

## 🚀 Features (Bot eke thiyena wada kaali)

- 🤖 **AI Assistant:** `.ai <query>` saha `.imagine <prompt>` (Free AI & Image Generator)
- 👥 **Group Controls:** `.tagall`, `.hidetag`, `.kick`, `.promote`, `.demote`, `.groupinfo`
- 🎨 **Media & Stickers:** `.sticker` (Image to sticker), `.tts` (Text to speech)
- 📥 **Downloaders & Search:** `.song`, `.video`, `.yts` (YouTube search)
- 🛠️ **Utility Tools:** `.calc` (Calculator), `.weather`, `.joke`, `.fact`
- ⚡ **Auto Features:** Auto status view, auto react, always online
- 🔗 **Easy Linking:** 8-digit **Pairing Code** haraha connect wena nisa camera scan karanna phone dekak oni na! Ekama phone eken connect wenna puluwan.

---

## 💻 Step-by-Step Setup Guide (WhatsApp ekata daganna widiha)

### 1️⃣ Step 1: Install Node.js
Oyaage computer eke thama **Node.js** neththam:
1. Me link ekata yanna: **[https://nodejs.org/](https://nodejs.org/)**
2. **LTS (Recommended For Most Users)** version eka download karala normal install karaganna (`Next > Next > Finish`).

---

### 2️⃣ Step 2: Configure Your Details
`config.js` file eka open karala oyaage WhatsApp number eka daaganna:
```js
ownerNumber: ["94712345678"], // Oyaage WhatsApp Number eka (94 ekka)
```

---

### 3️⃣ Step 3: Run the Bot
- Simple ma widiha: Folder eke thiyena **`start.bat`** file eka double click karanna!
- Neththam Terminal / PowerShell eken me commands denna:
```bash
npm install
npm start
```

---

### 4️⃣ Step 4: Link to WhatsApp (Pairing Code)
1. Bot run weddi terminal eke ahanawa:
   `👉 Enter your WhatsApp phone number with country code (e.g. 94712345678):`
2. Oyaage WhatsApp number eka type karala **Enter** karanna.
3. Terminal eke **8-digit Pairing Code** ekak enawa (e.g. `ABCD-1234`).
4. Dan oyaage phone eke WhatsApp open karanna:
   - **Settings** (or 3 dots) -> **Linked Devices** (සම්බන්ධිත උපාංග)
   - **Link a Device** (උපාංගයක් සම්බන්ධ කරන්න)
   - Yatin thiyena **"Link with phone number instead"** (දුරකථන අංකය මගින් සම්බන්ධ කරන්න) click karanna.
   - Terminal eke aapu **8-digit code** eka enter karanna!

🔥 **DONE!** Oyaage **PASIYA-MD** bot WhatsApp ekata connect wela iwarai!
WhatsApp ekata gihin **`.menu`** kiyala message ekak yawala balanna!
